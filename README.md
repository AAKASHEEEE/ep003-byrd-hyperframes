# EP003 Byrd — Hyperframes source

HyperFrames source for episode 003 ("Byrd: 136 days alone"), split into 12 chunks (`chunk-a` … `chunk-l`).

Each chunk contains:

- `package.json`, `hyperframes.json`, `index.html`, `meta.json`
- `compositions/` — scene HTML compositions
- `tools/` — build, audio and cue scripts, plus per-scene generators in `tools/scenes/`

Audio/image assets (`assets/`) and rendered videos are not included in this repo.
